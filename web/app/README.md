# CIFEDRA Connect Alliance Board

Статический пользовательский прототип рабочей страницы CIFEDRA Connect.

## Назначение

Страница показывает, где пользователь будет работать после лендинга:

- создает и уточняет `Ally Request`;
- смотрит AI Matching и объяснение релевантности;
- выбирает союзника;
- двигает процесс через `Intro`, `Agreement`, `Active Alliance`, `Result`;
- видит состояние запросов и союзов на `Alliance Board`.

## Локальный просмотр

```text
http://localhost:4177/web/app/
```

Запуск из корня проекта:

```bash
npm run local:start
```

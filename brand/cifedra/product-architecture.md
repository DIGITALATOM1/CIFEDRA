# CIFEDRA Product Architecture

`CIFEDRA CONNECT` - навигатор полезных людей. Архитектура строится вокруг трех пользовательских контекстов: жизнь, работа, навыки.

## 1. CIFEDRA Life

Люди для жизни, дома и локальной помощи.

| Категория | Назначение |
| --- | --- |
| `Home Help` / `Помощь по дому` | Уборка, клининг, сборка мебели, мелкий ремонт, сантехника, электрика, установка техники. |
| `Local Tasks` / `Поручения рядом` | Забрать, отвезти, купить, встретить, помочь на месте, съездить вместо пользователя. |
| `Move & Transport` / `Переезды и перевозки` | Грузчики, машина, упаковка, вывоз вещей, помощь при переезде. |
| `Care` / `Забота и уход` | Няни, сиделки, помощь пожилым, выгул животных, передержка, сопровождение. |
| `Local Deals` / `Локальные сделки` | Купить, продать, арендовать у людей рядом, обменяться вещами, договориться о разовой помощи. |

## 2. CIFEDRA Work

Люди для работы, бизнеса, проектов и сделок.

| Категория | Назначение |
| --- | --- |
| `Expert Help` / `Экспертная помощь` | Консультация, ревью, диагностика проблемы, второе мнение, разбор ситуации. |
| `Task Execution` / `Исполнение задач` | Найти специалиста или подрядчика: дизайн, разработка, аналитика, тексты, юридическая помощь, бухгалтерия, маркетинг. |
| `Business Deals` / `Бизнес и сделки` | Клиенты, партнеры, поставщики, подрядчики, инвесторы, франчайзи, агенты, представители. |
| `Project Team` / `Команда под проект` | Собрать людей под MVP, запуск, мероприятие, исследование, рабочую инициативу. |
| `Company Knowledge` / `Люди внутри компании` | Найти того, кто знает систему, процесс, клиента, документ, решение или может согласовать вопрос. |

## 3. CIFEDRA Skills

Люди для обучения, развития и обмена опытом.

| Категория | Назначение |
| --- | --- |
| `Mentors` / `Менторы` | Наставники по профессии, бизнесу, карьере, переходу в новую сферу. |
| `Learning Help` / `Обучение` | Репетиторы, преподаватели, тренеры, объяснение сложных тем, индивидуальные занятия. |
| `Career Help` / `Карьера` | Подготовка к собеседованию, ревью резюме, разбор портфолио, карьерная стратегия. |
| `Practice Partners` / `Практика` | Разговорный английский, mock interview, разбор кейсов, совместное решение задач. |
| `Skill Exchange` / `Обмен навыками` | Я учу тебя одному, ты меня другому. Или взаимная практика без денег. |

## Navigation Rule

В интерфейсе направления должны отвечать на вопрос пользователя: "Для какой сферы мне нужен человек?"

После выбора направления пользователь уточняет:

1. Что нужно сделать.
2. Где или в каком контексте это нужно.
3. Какой результат должен быть после контакта.
4. Кто может помочь: человек, эксперт, исполнитель, партнер, наставник или локальный помощник.

## Product Implication

Каждая категория должна приводить к одному и тому же ядру сценария:

`Need -> Match -> Prepare -> Connect -> Result`.

Разница между направлениями не в механике, а в словаре, фильтрах, доверии и типе результата.

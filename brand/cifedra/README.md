# CIFEDRA Brand Guide

Стартовое направление бренда для стартапа `CIFEDRA / ЦИФЕДРА`.

## Решение по названию

Основное имя: `CIFEDRA`.

Причина: латиница лучше работает для домена, продукта, репозиториев, интерфейсов, международных материалов и технологического позиционирования. `ЦИФЕДРА` стоит использовать как русскую локализацию в документах, презентациях, обучающих материалах и внутренней коммуникации.

## Идея знака

Знак строится вокруг живой монолинии из референса: петля, орбита, путь, цикл развития. Внутренний акцент добавляет системность: это не просто ручная линия, а управляемая траектория роста.

Смысловые ассоциации:

- системность без бюрократической тяжести;
- развитие базы знаний и продукта;
- аналитический путь от хаоса к структуре;
- связка цифрового, образовательного и методологического подхода.

## Логотипы

- `logo-cifedra-primary.svg` - основной горизонтальный логотип.
- `logo-cifedra-cyrillic.svg` - русская локализованная версия.
- `logo-cifedra-inverted.svg` - версия для темного фона.
- `logo-mark.svg` - компактный знак для favicon, аватаров и иконок.

## Типографика

Рекомендуемый стек:

- Основной: `Manrope`.
- Альтернатива: `Inter`.
- Системный fallback: `Segoe UI`, `Arial`, `sans-serif`.

Для логотипа и заголовков использовать плотный гротеск с уверенным весом `700-800`. Для интерфейсов и базы знаний использовать `500-600` в заголовках и `400-500` в основном тексте.

## Правила использования

- Не деформировать знак и не менять пропорции.
- Не использовать знак поверх шумных фото без подложки.
- Для маленьких размеров использовать только `logo-mark.svg`.
- Минимальная высота горизонтального логотипа: `32px` в интерфейсе, `18mm` в печати.
- Охранное поле: не меньше половины высоты знака вокруг логотипа.
- Основное написание в продукте: `CIFEDRA`. В русских текстах допустимо: `CIFEDRA (ЦИФЕДРА)` при первом упоминании.

## Тон коммуникации

`CIFEDRA` говорит как системный аналитик с продуктовым мышлением: точно, структурно, без лишней сложности. Бренд не должен выглядеть как академическая кафедра или корпоративная канцелярия. Он должен ощущаться как рабочая среда, которая помогает превращать хаос требований в понятную систему.

## UI-направление

- Фоны: светлый `Paper` или темный `Ink`.
- Основные панели: белые или очень светлые, без тяжелых теней.
- Акцентные действия: `Teal`.
- Статусы роста, успеха и прогресса: `Lime`.
- Ручные пометки, методические блоки и подсказки: `Brass`.
- Радиусы: `8-14px` для рабочих интерфейсов, до `24px` для брендовых блоков.

## Следующие шаги

1. Проверить, подходит ли смысловой вектор: системная аналитика, база знаний, SRS, постановки, инструкции.
2. Выбрать слоган: оставить `Systems that grow` или заменить на русскую формулу.
3. Подготовить вторую итерацию знака: более строгую, более живую или более технологичную.
4. Перенести выбранную версию в Figma и собрать библиотеку компонентов.

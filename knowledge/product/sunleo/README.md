# SUNLEO — CJM пилота ПВУ

[Открыть HTML-карту трёх ролей](./index.html).

Артефакт для обсуждения концепции, не действующий сервис записи или оплаты.
Открывается напрямую в браузере без сборки; файлы HTML, CSS и JavaScript должны находиться рядом.
Для каждой роли доступны шесть этапов, действия, ожидания, точки контакта,
трудности, предложенный ответ MVP и результат. Кнопка печати выводит все три CJM.

## Подтверждено инициатором

- SUNLEO — сообщество / союз парикмахеров и сервис организации взаимодействия.
- Пилот: одно помещение SUNLEO на юге Москвы, три рабочих места.
- Клиент выбирает мастера, мастер выбирает помещение по потребностям и ресурсам.
- Приглашаются мастера с разным опытом; опыт и отзывы влияют на выбор.
- Клиент платит через сервис. Услугу оказывает мастер и отвечает за её качество.
- Владелец ПВУ обеспечивает расходники, уборку, доступ, встречу и организационное решение обращений. Конкретная комплектация ещё не описана.
- Бренд может измениться. Аналогия с Ozon относится к организации площадки взаимодействия; это не аффилированный с Ozon продукт.

## Уточнения версии 0.2

[Декомпозиция, принятые правила и состояния](./decomposition.md).

Мастер не платит за место без клиента и оказанной услуги. Мастер заранее выбирает ПВУ, клиент ищет мастера в удобном ПВУ. SUNLEO задаёт цену и длительность по общим правилам. Деньги резервируются; момент окончательного списания ещё не определён. Предоставляется весь стандартный комплект, перечень требуется уточнить. Запись автоматическая при подтверждении мастером; что именно он подтверждает, пока открыто.

## Рабочие гипотезы

Мастер заранее выбирает ПВУ, после чего открывает клиентам время с видимым адресом.
Запись проверяет доступность мастера, рабочего места и общих ресурсов.
В CJM до визита показан резерв денег. Момент резерва и окончательного списания не утверждён.
Сервис ведёт отдельные статусы записи, платежа и обращения.
Проблемы качества направляются мастеру, помещения — владельцу, платежа — сервису.
Это продуктовые границы концепции, не юридическое заключение о распределении ответственности.

## Решения до реализации транзакционного MVP

1. Тариф места, комиссия, получатели и порядок выплат.
2. Общие правила SUNLEO для цены и длительности услуг.
3. Момент оплаты, срок удержания слота, отмены, возвраты и неявки.
4. Состав ресурсов, учёт общих ресурсов и время подготовки между визитами.
5. Допуск мастеров, проверка опыта, публикация и модерация отзывов.
6. Подтверждение завершения услуги и обработка претензий.
7. Срок пилота и критерии успеха: кандидаты — загрузка мест, визиты, повторные записи, отмены и экономика визита. Цели не заданы.

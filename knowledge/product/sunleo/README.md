# SUNLEO — пилот ПВУ

SUNLEO — сообщество парикмахеров и сервис взаимодействия владельца площадки, мастеров и клиентов. Пилот проводится в одном помещении на юге Москвы с тремя рабочими местами.

Текущий этап — локальный MVP с тестовым платёжным адаптером. Реальные банковские резервы, списания и выплаты в него не входят. Наличие спецификации само по себе не означает готовность функций: реализация проверяется по критериям приёмки.

## Согласованная модель

Мастер заранее бронирует одно рабочее место на весь день 09:00–21:00 по московскому времени. Место принадлежит его брони независимо от клиентских записей. Клиент выбирает мастера в удобном ПВУ и автоматически записывается на свободное время внутри забронированного дня. SUNLEO определяет цены и длительность услуг.

Мастер вносит 5 000 ₽ за день. Это невозвратный минимум в пользу ПВУ, включая простой и неявку мастера, который засчитывается в долю ПВУ по схеме 50/50. При выручке дня R доля ПВУ равна max(5 000, R / 2), итог мастера — R минус доля ПВУ. Уже внесённые 5 000 ₽ нельзя удерживать повторно. Комиссия SUNLEO в пилоте — 0%.

Деньги клиента резервируются через сервис; подтверждение мастером оказанной услуги запускает списание. Услугу оказывает мастер и отвечает за её качество. Владелец ПВУ обеспечивает стандартный комплект, расходники, уборку, доступ, встречу клиента и организационное решение обращений. Точный перечень комплекта ещё предстоит согласовать.

## Источник и открытые решения

Источник требований — последовательные ответы инициатора в текущей задаче от 12.09.2026. Последние согласованные условия заменяют прежнюю гипотезу «без услуги мастер не платит». Бренд SUNLEO может измениться.

[Действующий сайт SUNLEO](https://sunleo.ru/) используется как контекст бренда; его салонные цены не становятся автоматически тарифами ПВУ. Аналогия с Ozon относится к организации площадки взаимодействия.

До реальных операций нужно определить отмены и возвраты, точную комплектацию, каталог и тарифы услуг, доступ и допуск мастеров, эквайринг, сроки резервирования, выплаты, проверку полномочий и обработку обращений. Полный список и границы текущего MVP приведены в спецификации. Продуктовое распределение ролей не является юридическим заключением о распределении ответственности.

## Запуск первого рабочего среза

Из корня проекта: `npm run sunleo:dev`. Открыть [локальный SUNLEO MVP](http://127.0.0.1:5188/sunleo). Остановить оба процесса через Ctrl+C. Для запуска нужны уже установленные зависимости проекта (`npm install`). Порты: 5188 (интерфейс), 3038 (SUNLEO API).

1. В роли парикмахера выбрать дату, тестовый профиль и свободное кресло; внести тестовые 5 000 ₽.
2. В роли клиента выбрать мастера, услугу и время; использовать вымышленное имя и создать тестовый резерв.
3. Вернуться к тому же мастеру и подтвердить оказание услуги. В тесте это возможно сразу, без ожидания времени визита.
4. В роли владельца проверить долю ПВУ и календарь. В расчёте мастера отдельно показаны выплата из выручки и итог с учётом взноса.

Данные сохраняются в `.local/sunleo/store.json`, не в браузере и не в Git. Хранилище рассчитано на один процесс SUNLEO API на этом компьютере. Реальный пилот с людьми, банковскими операциями и независимыми аккаунтами требует следующего этапа. Тарифы услуг — тестовые, не коммерческое предложение.

Проверки: `npm run sunleo:test`, `npm -w @cifedra/web run build`, `npm -w @cifedra/api run typecheck`, `npm run docs:check`.

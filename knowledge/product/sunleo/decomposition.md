## Принятые бизнес-правила

| ID | Правило |
| --- | --- |
| BR-01 | Одно ПВУ на юге Москвы, три рабочих места. |
| BR-02 | Мастер заранее бронирует одно место на день 09:00–21:00, исключительно за собой; возможны несколько дней. |
| BR-03 | Клиент выбирает мастера в ПВУ; свободная запись внутри дня принимается автоматически без отдельного подтверждения мастера. |
| BR-04 | SUNLEO задаёт цены и длительность; условия сохраняются в записи. Конкретный каталог ещё не утверждён. |
| BR-05 | Клиентские деньги резервируются; подтверждение мастером оказанной услуги запускает списание. |
| BR-06 | Мастер вносит 5 000 ₽ за день. Минимум не возвращается при простое или неявке и засчитывается в долю ПВУ. |
| BR-07 | Доля ПВУ = max(5 000 ₽, 50% выручки дня); итог мастера = выручка минус доля ПВУ; комиссия SUNLEO = 0. |
| BR-08 | ПВУ предоставляет полный стандартный комплект, перечень ещё не определён. Мастер отвечает за услугу, владелец — за организацию площадки. |

Прежнее правило «нет услуги — нет платы» отменено. Сравнение резерва с Яндекс Такси не определяет банковские сроки и технические ограничения.

## Модель состояний для реализации

- Дневная бронь места: доступно → забронировано → день завершён. Неявка не отменяет минимум 5 000 ₽. Правила отмены до дня требуют отдельного решения.
- Клиентская запись: создание → подтверждена автоматически → услуга завершена мастером. При сбое резерва запись не становится оплаченной/готовой к обслуживанию молча; повтор и восстановление результата должны быть согласованы с состоянием адаптера.
- Платёж: резерв ожидается → зарезервирован → списание ожидается → списан. Ветки: ошибка, неопределённый результат. Реальные истечение резерва, снятие и возврат — последующий этап.
- Расчёт дня: предварительный → итоговый после сверки услуг и списаний. Ошибка списания остаётся задолженностью/ошибкой, а не успешным поступлением или выплатой.

Завершение услуги, успешное списание и выплата участникам — разные события. Переключение ролей в локальной демонстрации не заменяет авторизацию.

## Следующие пакеты работ

1. Локальный сквозной путь: бронь дня → выбор мастера → автоматическая запись → тестовый резерв → завершение мастером → тестовое списание → расчёт.
2. Исключения: отмена, перенос, неявка клиента, сбой площадки, частичная услуга, возврат и спор.
3. Операции ПВУ: точный состав комплекта, общие ресурсы, подготовка, допуск и физический доступ.
4. Реальные платежи и доступ: провайдер, сроки резерва, получатели, выплаты, авторизация и сверка.
5. Измерение пилота: загрузка 3 мест, выполненные услуги, повторные записи, отмены, фактическая экономика. Сроки и целевые значения пока не заданы.

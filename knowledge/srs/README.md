# SRS Knowledge Base

Раздел хранит утверждаемые требования к поведению CIFEDRA:

- scope and actors;
- functional and non-functional requirements;
- invariants and lifecycle;
- authorization;
- acceptance criteria;
- traceability to CJM, architecture, code and tests;
- review history.

SRS не должен зависеть от конкретного UI или внешнего продукта, если это не
является явным требованием.

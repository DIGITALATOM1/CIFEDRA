# Research

Раздел хранит:

- interview plans and scripts;
- participant trackers без лишних персональных данных;
- обезличенные notes;
- evidence synthesis;
- usability research.

## Privacy rules

1. Использовать participant code вместо полного имени в notes.
2. Не сохранять confidential SRS or project details до gate D0.
3. Фиксировать согласие на notes/recording.
4. Удалять данные по запросу participant.
5. Отделять direct evidence, interpretation and product decision.
